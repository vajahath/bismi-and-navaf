# A flower for you

A mobile-first jungle wedding game for Bismi and Navaf.

Tap, click, or press Space to guide the rose. Avoid obstacles and carry it to your person.

## Preview locally

Run `python3 -m http.server 4173` and open http://localhost:4173. No build step is required.

## Add your photos

Place photos in `assets/memories/` and set each photo’s `src` and `caption` in `memories.js`. There are 15 slots. Empty slots use illustrated placeholders.

## Publishing

GitHub Pages serves the root of the `main` branch. Pushing to `main` updates the game.
